# 🎓 AI Placement Prediction System

A Machine Learning based web application that predicts whether a student is likely to get placed based on academic performance, projects, internships, aptitude score, workshops/certifications, and soft skills.

## 🚀 Project Overview

The AI Placement Prediction System uses Machine Learning to analyze student-related features and predict placement status.

The trained ML model is integrated with a Flask web application, allowing users to enter student information through an interactive web interface and receive a placement prediction.

## ✨ Features

- 📊 Student placement prediction using Machine Learning
- 🧠 Trained classification model
- 🌐 Interactive Flask web application
- 📝 Student information input form
- ⚡ Instant prediction results
- 📈 Data preprocessing and feature scaling
- 🔄 Encoded categorical features
- 💻 User-friendly interface

## 📌 Input Features

| Feature | Description |
|---|---|
| CGPA | Student's academic performance |
| Projects | Number of projects completed |
| Internships | Number of internships completed |
| Aptitude Test Score | Aptitude test score |
| Workshops/Certifications | Number of workshops or certifications |
| Soft Skills Rating | Rating of student's soft skills |
